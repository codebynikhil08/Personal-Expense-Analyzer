# Personal Expense Analyzer

## About the Project
A beginner-friendly Data Science project that analyzes personal expenses using Python. It explores spending patterns across categories and payment methods and visualizes the results using charts.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Features
- Loads expense data from a CSV file
- Calculates total and average transaction amounts
- Groups expenses by category and payment method
- Filters transactions using conditions
- Visualizes spending with bar and pie charts
- Identifies highest- and lowest-spending categories

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib`
3. Open `expense_analyzer.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.

## Dataset
The project uses sample expense transactions for demonstration. The figures do not represent actual personal spending.
